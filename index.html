Política de Privacidade - Sistema de Backup Enigma

Última atualização: 06 de novembro de 2026

Esta política explica como o Sistema de Backup Enigma ("aplicativo") trata os dados. O aplicativo é desenvolvido pela Enigma Automação e é de uso interno, para envio automatizado de arquivos de backup para o Google Drive.

1. Quais dados são acessados

  • Arquivos de backup (.zip): o aplicativo lê os arquivos .zip da pasta local configurada no computador onde está instalado.
  • Dados da conta Google: o aplicativo usa autorização OAuth 2.0 com o escopo drive.file. Ele só acessa os arquivos e pastas que ele mesmo criou no Google Drive. Não lê, altera nem apaga outros arquivos da conta.
  • Dados de configuração: nome do cliente, CNPJ e caminho da pasta local, gravados no computador do usuário.

2. Como os dados são usados

Os dados são usados somente para:

  • enviar os arquivos de backup para uma pasta, criada automaticamente, nomeada com o nome do cliente e o CNPJ;
  • manter no Google Drive apenas os 4 backups mais recentes de cada cliente;
  • registrar erros e eventos de envio em um arquivo de log local.

3. Com quem os dados são compartilhados

Os arquivos de backup são enviados apenas para a conta Google Drive do responsável pelo sistema. Não há venda, cessão ou compartilhamento de dados com terceiros. O aplicativo não usa ferramentas de análise, publicidade ou rastreamento.

4. Armazenamento e segurança

  • O token de acesso fica armazenado localmente no computador do usuário, em uma pasta de configuração do aplicativo.
  • Os arquivos de backup permanecem no Google Drive pelo tempo definido na política de retenção (4 backups por cliente). Os arquivos excedentes são movidos para a lixeira do Drive, onde ficam disponíveis por 30 dias antes da exclusão definitiva.

5. Uso dos dados obtidos da API do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário das APIs do Google, incluindo os requisitos de Uso Limitado.

6. Seus direitos

Você pode, a qualquer momento, parar o aplicativo, desinstalá-lo, revogar o acesso ao aplicativo nas configurações da sua conta Google em myaccount.google.com/permissions e solicitar a exclusão dos dados enviados, entrando em contato pelo e-mail abaixo.
